## Not here yet

**`troubleshooting.md` has no page of its own, on purpose.** Every symptom
already has an address that answers a *different* question about it:
[WORKFLOW.md](WORKFLOW.md) reads "this function never shows argument data",
"two live instances, one namespace" and "a misspelled option gets one warning"
back to their cause, and `:checkhealth runtime-analysis` covers the
environment. A third document would repeat both rather than add one.

## Here, but not prose

**`install.json`** declares the external tools this plugin can use,
machine-readably, for `:Lib deps show runtime-analysis.nvim`. **`map/`** is the
generated module map — one of the two repositories in the collection that
actually ships it; [`map/overview.md`](map/overview.md) is the same tree as
Markdown, regenerated by `scripts/gen_map.lua` (see
[installation.md](installation.md#dev-only-the-module-map)).
